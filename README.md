# Library App

LibraryApp - система автоматизации работы библиотеки с элементами рекомендаций и отчетности.

## Описание проекта

Приложение предназначено для библиотекарей и читателей. Оно позволяет управлять книгами, читателями, мероприятиями, отзывами и рекомендациями. Реализована система авторизации, выдачи/приема книг, фильтрации и поиска, а также модуль статистики с выгрузкой в Excel.

Приложение разработано в рамках дипломного проекта.

## Основной функционал

### Авторизация и роли
- Вход по логину и паролю.
- Проверка на незаполненные или некорректные данные.
- Для читателей с приближающимся сроком сдачи книг — автоматическое уведомление при входе.

### Книги
- Добавление, редактирование, удаление (только доступных книг).
- Отображение обложки (стандартная, если отсутствует).
- Сортировка, фильтрация и поиск в реальном времени (по коду, названию, автору).
- Для читателей — отображаются только книги в наличии.

### Читатели
- Просмотр списка читателей, поиск по ФИО.
- Удаление читателя только при отсутствии книг на руках.

### Мероприятия
- Добавление, редактирование, удаление.
- Запись читателей на мероприятия.
- Невозможность записи на прошедшее мероприятие.

### Отзывы
- Читатели могут добавлять, редактировать и удалять свои отзывы к книгам.
- Библиотекарь может удалять любые отзывы.
- Отображение отзывов других читателей.

### Статистика
- Посещаемость мероприятий.
- Популярные книги.
- Активные читатели.
- Экспорт данных в Excel.

### Рекомендации
- На основе данных о книгах и предпочтениях формируются рекомендации для читателей.
